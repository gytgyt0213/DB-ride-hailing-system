实现说明
数据来自视图 v_expiring_licenses。 它用 UNION ALL 把三种证照 （司机驾驶证、车辆保险、车辆年检）统一成 「主体类型 + 主体 + 证照类型 + 到期日 + 剩余天数」的同一结构， 剩余天数由 DATEDIFF(到期日, CURDATE()) 计算。
本机 MySQL 的 event_scheduler 处于开启状态， 因此也可以用 MySQL 定时事件（EVENT）每天自动扫描并生成提醒， 而不必依赖外部定时任务。
